我是 Guanqi，一名独立工程师。现在主要围绕 BitFun 做事：把 Code Agent、Cowork Agent 和 Computer Use 这些能力接到一个可持续的 desktop runtime 里。

我更在意的是运行时本身：会话、工具、记忆、状态、调试和长任务执行要能看见、能追踪、能复用。BitFun 吸引我的地方，就是它不是一个演示壳子，而是一个真的要拿来干活的系统。

这个站点会以 blog 为主，记录我在 BitFun 相关工作里学到的东西：怎么拆分能力、怎么接入桌面工作流、以及怎么让 agent 的行为更可控。
