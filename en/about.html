I am Guanqi, an independent engineer currently focused on BitFun: connecting Code Agent, Cowork Agent, and Computer Use into a durable desktop runtime.

I care about the runtime itself: sessions, tools, memory, state, debugging, and long-task execution should be visible, traceable, and reusable. What makes BitFun interesting to me is that it is meant to do real work, not just demo an interface.

This site is blog-first. I use it to write down what I learn from BitFun-related work: how to split capabilities, how to attach them to desktop workflows, and how to keep agent behavior controllable.
