BitFun 吸引我的地方，是它把 agent 当成一个真实工作的系统，而不是一个 prompt demo。

我更在意的不是“能不能说话”，而是它能不能稳定做事：会话是否可追踪，工具调用是否可见，状态是否能恢复，长任务是否能继续。

BitFun 如果做对了，应该能让 Code Agent、Cowork Agent 和 Computer Use 真的进入一个可持续的桌面工作流，而不是停留在概念展示。

我关心的是运行时本身：state、memory、调试、恢复、工具协议和用户能不能掌控它们。
