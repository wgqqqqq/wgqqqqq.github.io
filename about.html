我是 Guanqi，关注本地优先的 AI 开发工具和 agent runtime。我的工作不是只做一个聊天界面，而是把 agent 真正在工程环境里需要的基础能力做扎实：搜索、索引、状态、工具调用、长任务和桌面集成。

目前工作重心在 BitFun。我关心的是 agent 怎么在真实 workspace 里持续工作：代码仓库怎么搜、上下文怎么恢复、工具调用怎么追踪、长任务怎么中断后继续，以及 desktop runtime 怎么承载这些能力。

另一条线是 flashgrep。它是一个面向大型 Git worktree 的本地 regex 预筛索引系统：先用字符级倒排索引召回候选，再做精确 regex 验证。这个项目更能代表我对“agent 工具链基础设施”的理解：速度、正确性、增量状态和对外协议都要一起成立。

当前主线

  • BitFun：desktop-grade agent runtime 和 agent app 工作面。
  • flashgrep：给 agent 和大型仓库使用的本地搜索 / 索引基础设施。

关注方向

  • Agent runtime：会话、工具、memory、状态、调试和长任务执行。
  • Workspace search：regex 预筛索引、base snapshot、published overlay、daemon 协议。
  • Local work surfaces：filesystem、terminal、browser、computer use 如何组成一个可控的工作面。
